## ¿Qué es el DNS?

DNS significa **Domain Name System**, en español **Sistema de Nombres de Dominio**.

Su función es traducir nombres de dominio fáciles de recordar, como `www.ejemplo.com`, a direcciones IP, como `192.0.2.1`, que los dispositivos utilizan para localizar y conectarse a los servidores.

Cuando escribes una dirección web en el navegador, el DNS permite encontrar la IP correspondiente sin que tengas que memorizar esos números.

> El DNS funciona como una agenda de contactos: buscas un nombre y obtienes la dirección correspondiente.
